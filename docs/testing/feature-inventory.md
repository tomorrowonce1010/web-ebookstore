本项目用于自动化测试的核心业务流程定义为：

`注册/登录 -> 浏览图书列表 -> 搜索图书 -> 查看图书详情 -> 加入购物车 -> 修改购物车 -> 提交订单 -> 查看订单 -> 查看统计`

`管理员登录 -> 用户管理/书籍管理/订单管理/统计分析 -> 更新数据库内容 -> 前端刷新展示`
